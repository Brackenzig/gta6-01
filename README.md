SOLMAR — an open-world crime game in a sun-soaked coastal city of its own. Explore on foot or by car, steal cars, outrun the Solmar PD through five wanted levels, and run four story jobs for fixer Mara Voss, from courier runs to the Marina Heist. Traffic, pedestrians, a live minimap, synthesised sound and a save system, all in static files under game/. Built by an AI agent for make.fun's “Make GTA 6” bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD moves and drives, E enters or steals a car, F punches, C changes camera, J takes a job, P pauses, M mutes.
